# 靜默之島：選擇與代價

白色恐怖情境模擬遊戲。一位關主、6 到 8 位玩家，玩 6 個回合。每個人在高壓社會裡面對道德兩難，再看大家的選擇累積出什麼樣的結局。

關主在電腦上操作控制面板，玩家用手機掃 QR Code 加入。伺服器用 Python（FastAPI + WebSocket）寫。

## 怎麼玩

1. 關主在電腦開首頁，點「建立房間」，畫面會出現房間碼和 QR Code。
2. 玩家用手機掃 QR Code（或輸入房間碼和名字）加入。6 人才能開始，最多 8 人。
3. 關主按「開始遊戲」，系統隨機分配角色。玩家先看自己的身分，確認後才開始。
4. 每個回合：
   - 關主按「下一事件」，所有人看到同一個事件。
   - 關主按「沉默倒數」，全員安靜 5 秒。
   - 關主可以選 1、2、3、5 分鐘的討論時間，也可以跳過。
   - 關主按「開始投票」，每位玩家有 30 秒，在三個選項裡選一個。
   - 關主按「結束投票」，系統結算。
5. 6 個事件依序是：思想調查、同事私下詢問、讀書會傳聞、夜間約談、舊事被翻出、上級要求全面配合。第 5 個事件由系統自動結算前面留下的「伏筆」。
6. 第 6 回合結束後，關主按「顯示結局」。

## 規則重點

- **兩個共同數字**：社會恐懼、思想流通。每個選擇都會推動它們，最後由這兩個數字決定全體結局。
- **個人風險**：每位玩家有自己的風險值。風險到 10 會被「帶走」，之後轉成觀察者，只能看，不能投票。
- **匿名紙條**：每位玩家一場最多傳 3 張，每張最多 100 字。
- **角色**：7 種，各有一個被動效果和一次性能力。6 人局固定有 A–D 四種，7 人加入 E、F，8 人再加入 G；人數不足時用一般市民補齊。

| 代號 | 角色 | 被動 | 一次性能力 |
|---|---|---|---|
| A | 中學教師 | 第 2、4、6 回合結算後，社會恐懼 +1 | 選「迴避」時不產生伏筆 |
| B | 公務員 | 選「抵抗」時，個人風險額外 +1 | 取消本回合社會恐懼 +1（一次） |
| C | 大學生 | 選「抵抗」時，個人風險額外 +1 | 把本回合的 +1 風險改成社會恐懼 +1 |
| D | 旁觀者 | 社會恐懼 ≥ 3 時，無法選「抵抗」 | 替另一位玩家承擔一次 +1 風險 |
| E | 一般市民 | 無 | 取消本回合「多數壓力」造成的社會恐懼 +1 |
| F | 基層執行者 | 無 | 本回合改為公開投票，選「抵抗」的人額外 +1 風險 |
| G | 親屬 | 無 | 把任一位玩家的 +1 風險轉成社會恐懼 +1 |

## 結局

全體結局有五種，由兩個共同數字決定：

| 結局 | 條件 |
|---|---|
| 全面噤聲 | 恐懼 ≥ 6 |
| 短暫的春天 | 恐懼 = 0，流通 ≥ 4 |
| 表面穩定 | 恐懼 ≥ 4，流通 ≤ 1 |
| 緊繃未崩 | 恐懼 ≥ 4，流通 2–3 |
| 裂縫中的光 | 恐懼 ≤ 2，流通 ≥ 2 |

每位玩家另外會看到自己的結語：被帶走、道德代價（選過「提供資訊」或「舉報」）、道德崩解（簽了聲明）、倖存、普通人。

## 怎麼跑

需要 Python 3.11 和 Node.js 20（Node 只有要玩 React 版玩家頁面時才需要）。

```bash
# 取得程式
git clone https://github.com/kiresakura/silent-island.git
cd silent-island

# 安裝後端
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# （選用）建置 React 版玩家頁面，網址是 /play
cd client-react && npm install && npm run build && cd ..

# 啟動
uvicorn server.main:app --host 0.0.0.0 --port 8001
```

- 關主開 `http://localhost:8001`，玩家掃 QR Code 加入。
- 沒有建置 React 版時，QR Code 會導到舊版玩家頁面（`/player`）。
- 人不夠時：關主建好房間後，另開終端機跑 `python3 test_bots.py 房間碼`，機器人會自動加入並投票（連到 `localhost:8001`）。
- 專案也附 `Dockerfile` 和 `Procfile`，用 `PORT` 環境變數決定埠號（預設 8001）。
- 線上試玩網址：待補。

```
└── README.md
```
